Note : ECHO was developed and tested using Python 3.10.x. 
To ensure compatibility and avoid dependency issues, please use a Python 3.10.x version.

Recommended Version :Python 3.10.11

Download : https://www.python.org/downloads/release/python-31011/

Step 1 : Clone the repository

-> git clone https://github.com/Rishi18360/ECHO.git

Step 2: Navigate to the project folder

-> cd ECHO

Step 3: Open the project in VS Code

-> code .

Step 4: Create a virtual environment

-> python -m venv .venv

Step 5: Activate the virtual environment

-> .venv\Scripts\activate

Step 6: Install the required dependencies

-> pip install -r requirements.txt

Step 7: Run the application

-> python main.py
