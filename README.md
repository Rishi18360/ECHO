Note : ECHO was developed and tested using Python 3.10.x. 
To ensure compatibility and avoid dependency issues, please use a Python 3.10.x version.

Recommended Version :Python 3.10.11

Download : https://www.python.org/downloads/release/python-31011/
(Windows installer (64-bit))

Step 1 : Clone the repository

-> git clone https://github.com/Rishi18360/ECHO.git

Step 2: Navigate to the project folder

-> cd ECHO

Step 3: Open the project in VS Code

-> code .

Step 4: Create a virtual environment

-> python -m venv .venv

Step 5: Activate the virtual environment

-> .venv\Scripts\activate

Step 6: Install the required dependencies

-> pip install -r requirements.txt

Step 7: Run the application

-> python main.py

Selecting a Mode :
After launching ECHO, select a mode by holding up the corresponding number of fingers in front of the webcam:
1 Finger – Assistive Mode
2 Fingers – Presentation mode
3 Fingers – Communication Mode
4 Fingers – Entertainment Mode
Once a mode is selected, follow the on-screen instructions to perform the available gestures and actions.

Current Limitations :
- Supports only single-hand gesture recognition.
- Performance may vary under poor or uneven lighting conditions.
